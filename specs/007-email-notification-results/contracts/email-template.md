# Email Template Contract

**Feature**: 007-email-notification-results  
**Format**: HTML (XHTML 1.0 Transitional, UTF-8, table-based layout)

## Subject Line

Pattern: `Your car matches: {N} result(s) found`

- `{N}` is the integer count of matched listings (e.g., `3`)
- Examples: `Your car matches: 1 result(s) found`, `Your car matches: 7 result(s) found`

## Field Rendering Rules

| Field          | Format                        | Null/missing fallback                         |
| -------------- | ----------------------------- | --------------------------------------------- |
| `price`        | `€{value}` with comma separator (e.g., `€25,000`) | — (price is never null)   |
| `mileage`      | `{value} km` with comma separator (e.g., `45,000 km`) | `Not specified`        |
| `fuelType`     | Title case (e.g., `Petrol`)   | `Not specified`                               |
| `bodyType`     | Title case (e.g., `Hatchback`)| `Not specified`                               |
| `transmission` | Title case (e.g., `Automatic`)| `Not specified`                               |
| `seatCount`    | Integer                       | `Not specified`                               |
| `condition`    | Title case (e.g., `Used`)     | `Not specified`                               |
| `colour`       | Title case (e.g., `White`)    | `Not specified`                               |
| `features`     | Comma + bullet separated list | `No additional features listed`               |

Null/missing fallback styling: `color: #9ca3af; font-style: italic`

## Search Criteria Summary Rules

- Display each criterion only if it has a meaningful value (not null, not `"any"`, not `["any"]`)
- Budget: display as `up to €{budgetMax}` formatted with comma separator; omit if null
- Lists (bodyTypes, fuelTypes): join with `, `; omit if `["any"]`
- Transmission: display as title case; omit if `"any"`
- Minimum seats: display as integer; omit if null
- Features: display mandatory features only (mandatory: true) as a comma list; omit if empty
- If no criteria have meaningful values, display: `"No specific criteria applied"`

## Layout Constraints

- Max content width: **600px** (outer container)
- All styles: **inline only** (no `<link>`, no external CSS)
- Layout primitive: **`<table role="presentation">`** (no flexbox, no grid)
- Mobile: outer table `width="100%"` with `style="max-width:600px"` collapses naturally
- Left accent bar per card: narrow `<td>` (4px wide) with `background-color:#2563eb`
- Card separation: `margin-bottom:16px` on each card wrapper table
