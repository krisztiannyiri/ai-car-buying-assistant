# Implementation Plan: AI Chatbot Integration

**Branch**: `002-ai-chatbot-integration` | **Date**: 2026-08-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/002-ai-chatbot-integration/spec.md`

## Summary

Replace the static ChatInterface placeholder with a live Anthropic Claude API integration. The ChatInterface component becomes a `'use client'` component with full conversation state; a Next.js Route Handler (`app/api/chat/route.ts`) proxies requests to the Anthropic API server-side, keeping the API key out of the browser. Responses stream token-by-token so the user sees output appear progressively. A "New conversation" control cancels any in-flight stream via `AbortController` and resets history.

## Technical Context

**Language/Version**: TypeScript (constitution mandate) — Next.js 16.3.0 / React 19.2.8

**Primary Dependencies**:

- `next@16.3.0` — App Router, Route Handlers, `ReadableStream` response support
- `react@19.2.8` + `react-dom@19.2.8`
- `@anthropic-ai/sdk` — official Anthropic TypeScript SDK; model `claude-sonnet-4-6`; streaming via `client.messages.stream()`; typed error classes (`RateLimitError`, `APIStatusError`, `APIConnectionError`)

**Storage**: Browser memory only — conversation history held in React state for the duration of the page session; no server-side persistence

**Testing**: None (Constitution Principle V — no test frameworks permitted)

**Target Platform**: Web browser — modern browsers supporting `ReadableStream`, `fetch` with streaming body, and `AbortController` (Chrome, Firefox, Safari, Edge latest 2 major versions)

**Project Type**: Next.js web application (App Router — Route Handler for API, Client Component for ChatInterface)

**Performance Goals**: First streamed token visible within 3 seconds of message submission under normal network conditions (SC-001)

**Constraints**:
- `ANTHROPIC_API_KEY` must never be exposed to the browser — Route Handler proxy is mandatory
- No `any` TypeScript types
- No horizontal overflow at 320–1280px+; touch targets ≥44×44px
- Loading indicator shown until first token, then replaced by live stream (FR-004)
- Input disabled during streaming (FR-005)

**Scale/Scope**: Single-user browser session; up to 30 visible messages (SC-005); history pruned to 20 most-recent messages before each API call (FR-003)
